# BECOMING | 75 Days

This folder is ready to publish with GitHub Pages.

## Important: publish the CONTENTS of this folder
Extract the ZIP, then upload the files and `icons` folder directly into the top level of your GitHub repository. `index.html` must be visible at the repository's top level, not inside another nested folder.

Your repository should look like this:

- index.html
- manifest.webmanifest
- service-worker.js
- README.md
- icons/
  - icon-192.png
  - icon-512.png

## Enable GitHub Pages
1. Open the repository on GitHub.
2. Go to Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch `main` and folder `/(root)`, then Save.
5. Wait for GitHub Pages to publish, then open the HTTPS site URL.

## Install on Android
1. Open the published HTTPS URL in Chrome.
2. Wait for the page to finish loading.
3. Open Chrome's three-dot menu.
4. Choose Install app or Add to Home screen (the wording can vary).
5. Launch BECOMING from the home screen.

If Chrome does not offer installation, first visit the site in Chrome, reload it, and check that the manifest, both icons and `service-worker.js` load successfully. Browser menus and install eligibility can vary by Chrome version.

## Data and privacy
This is a local-first app. Progress and journal entries are stored in this browser on this device. Use the in-app Backup option regularly. There is no cloud sync or account in this version.
