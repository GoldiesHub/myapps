# BECOMING | 75 Days

A private, local-first progressive web app for the 75-day challenge.

## Included
- Daily view with six commitments and a rotating daily intention
- Daily reflection, private journal and weekly reviews
- Values compass and 75-day roadmap
- Local-device saving using browser storage
- JSON backup and CSV journal export
- Offline caching after the first visit when served over HTTPS

## Dates
The challenge is set for 22 November 2026 to 4 February 2027 (75 days inclusive).

## Test it
Open `index.html` in a modern browser to test the main experience. Your data stays in that browser on that device. Browser privacy settings or clearing site data can erase it, so use **Backup** regularly.

## Install on Android
For full home-screen installation and offline support, host the contents of this folder on a private HTTPS site (for example, a private GitHub Pages or Netlify deployment). Then open the HTTPS address in Chrome and choose **Install app** or **Add to Home screen** from the browser menu.

## Privacy and limitations
There is no account, server, analytics, or cloud sync in this first test version. Journal and progress data remain in local browser storage. The JSON backup is the portable copy. ChatGPT cannot see app activity automatically; export and share a backup or journal export when you want a review.
