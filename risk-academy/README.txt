QUICK START
1. Extract this ZIP.
2. Open index.html in a browser to use the app.
3. Your checklist and notes save locally in that browser on that device.

INSTALL AS AN APP
For the installable app experience and offline caching, publish the extracted folder to an HTTPS static host (for example, Netlify or GitHub Pages).
Then open the HTTPS address in Chrome on Android and choose Install app or Add to Home screen.

IMPORTANT
This is a web app package, not an Android APK. It does not sync data to the cloud. Export a backup from the Progress tab before clearing browser data or changing devices.
